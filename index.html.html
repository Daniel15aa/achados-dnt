01 / A ideia

Menos tarefas repetidas. Mais atenção aos detalhes.

Quem divulga ofertas conhece o trabalho por trás de cada publicação: encontrar o produto, conferir os dados e preparar uma mensagem clara. Queremos reunir essas etapas em um processo simples de acompanhar.

01 / PESQUISA⌕

Consultar produtos

Consultar títulos, preços, imagens e disponibilidade quando esses dados forem oferecidos pelos endpoints autorizados.

02 / CURADORIA◇

Escolher com critério

Aplicar critérios de seleção, organizar resultados e evitar repetir o mesmo produto sem necessidade.

03 / CONTEÚDO↗

Criar uma boa mensagem

Montar mensagens legíveis, com dados verificados, para revisão ou publicação futura em canais permitidos.

04 / Integração com o Mercado Livre

Por que precisamos da API?

Queremos consultar dados de produtos de forma estruturada, com autorização e dentro dos recursos disponibilizados pelo Mercado Livre. Essa é a base para construir uma curadoria automatizada confiável.

O projeto não pretende alterar anúncios, preços ou dados de vendedores. A obtenção de links de afiliado e a publicação automática dependem de mecanismos e autorizações próprios — não são funcionalidades presumidas da API.

✓
Dados dentro das permissõesConsulta apenas aos recursos efetivamente disponíveis e autorizados.
✓
Autenticação adequadaFluxo OAuth quando exigido, com credenciais protegidas no ambiente de execução.
✓

Dúvidas sobre o projeto

Perguntas frequentes

O Achados DNT é uma loja?

Não. Este site apresenta um projeto independente de automação e não vende produtos nem processa pagamentos.

Quais dados a aplicação pretende consultar?

Informações de produtos, como título, imagem, preço, link e disponibilidade, apenas quando disponibilizadas pelos endpoints e permissões autorizados.

A automação já publica ofertas?

Não. A infraestrutura de testes está configurada, mas a consulta real, os filtros e a publicação ainda dependem de desenvolvimento e validação das integrações permitidas.

Como serão tratados os links de afiliado?

Somente por mecanismos autorizados pelo Programa de Afiliados. O acesso à API não implica, por si só, permissão para gerar links rastreáveis.

Este é um projeto oficial do Mercado Livre?

Não. O Achados DNT é independente e não possui afiliação institucional ou endosso do Mercado Livre.
